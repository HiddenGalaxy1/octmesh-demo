# OctMesh interactive demo

Interactive visualization accompanying **OctMesh: A Unified Octree-Hierarchical Framework for Lossless Triangle Mesh Compression**.

Authors: Shiyu Feng, Xihua Sheng, Lingyu Zhu, Chunyang Fu, and Shiqi Wang.

Affiliation: City University of Hong Kong.

[Open the demo](https://hiddengalaxy1.github.io/octmesh-demo/)

The demo illustrates octree hierarchy construction and the four-stage connectivity reconstruction in Fig. 9. It includes freely rotating 3D views, mesh presets, and a detailed automatic walkthrough with side-by-side parent and child meshes.

This repository contains the interactive visualization. Neural inference and arithmetic coding are not executed, and the viewer is not a bitrate benchmark.
