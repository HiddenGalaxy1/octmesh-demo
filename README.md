# OctMesh demo

Interactive visualization of octree hierarchy and progressive mesh connectivity reconstruction.

The demo runs in the browser and includes preset meshes, freely rotating 3D views, and step-by-step parent-edge evolution. It illustrates the reconstruction process; it is not the neural encoder/decoder or a bitrate benchmark.

## Hosting

Serve this folder as a static website. For GitHub Pages, publish the `main` branch from the repository root. No build step is required.
